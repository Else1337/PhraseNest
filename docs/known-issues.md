# 已知问题与下一步

截至2026-10-31。区分已观察的问题、已做的修正和仍缺少的证据，不把代码存在写成所有场景都已验证。

## P0 · 多步作文批改可能中断

最近授权实验中，两版均未形成可用正文。工具曾读取超出真实总行数的范围，之后回退到文档开头，最后一步仍未取得目标原稿。

但最后供应商响应为HTTP200、finish_reason为stop，应用流却报错；缺少完整响应流与异常细节，不能断言唯一根因就是越界、模型或超时。

**下一步**：受控诊断；明确来源时提供完整目标段落；改进越界参数恢复；核对原稿覆盖与最终作答。047版本切换没有修复这条链路。

## P1 · 输入变短，不等于实际费用更低

**已做**：任务指南按需加载、稳定公共前缀、单步用量、重复片段复用与Observer参考输入处理。

**观察**：小样本中新版作文首步输入减少25.5%，但缓存较少，失败循环估算费用略高。15个工具schema仍有固定开销，多步会再次处理已有上下文。

**下一步**：分别测冷/热缓存，改进工具发现与原文复用，计入辅助记忆与重试；没有授权不追加付费请求。不用提示词缩短比例宣传相同费用降幅。

## P1 · 解析与检索需要更多真实版式验证

**已做**：原件、任务、版本、分块与索引分层；PDF、DOCX和图片解析；关键词、语义与混合检索工具。

**边界**：DOCX内图片、复杂公式与批注不保证完整还原；扫描PDF依赖OCR。旧DOC、PPT、XLS需先转换。已知来源读取不等于全库语义查询验收。

**下一步**：建立可公开的脱敏回归集，分别衡量解析完整度、检索相关性、引用正确性和端到端完成率。

## P1 · 教师闭环与规模化运行待完善

**已做**：班级、CSV批量账号、一次性激活、统一画像与证据复核。

**边界**：教师资料分发、作业发布—提交—批改—复核—报告仍需串联。多校身份、激活补发、多实例并发、大规模调度、记忆分片与灾备演练尚未充分验证。

## P2 · 移动端性能与切换文案

**已做**：流式更新隔离、按帧滚动、减少实时模糊与多层布局动画。

**观察**：长任务减少，但最终帧间隔未一致改善，低端设备仍需测量。版本按钮显示当前版本，点击切换到另一版，容易被误认为显示点击后的目标。

**下一步**：真机确认触摸、键盘和长回复；明确版本文案。这里只记录问题，不把未发布调整说成已修复。

## 教学有效性需要单独评估

能够展示原文证据、画像联动和练习机制，不等于已经证明长期提分、优于教师或其他产品。模拟数据、模型自评分和少量选项正确，不能替代真实教学研究。
