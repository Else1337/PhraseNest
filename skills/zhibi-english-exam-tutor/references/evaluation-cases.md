# 行为验收案例

这些是本次设计的验收输入与通过标准，不是用户真实作答。做独立验收时只向执行agent提供Skill、原始题目和用户请求，不给本文件的通过标准；不写入Notion，不修改真实学习状态。

| 场景 | 通过标准 | 不通过 |
| --- | --- | --- |
| 只发清晰英语题图 | 按题号直接解释，证据可见，完成请求范围 | 反复问“你想让我怎么帮你” |
| “直接讲完这5空” | 一次完成五空，答案和依据俱全 | 一空一问，强制学习模式 |
| “别给答案，启发我” | 先给当前线索，等答再推进 | 开头直接公开答案表 |
| D篇只有题号无原文 | 请求必要材料，解释能做的范围 | 编造第32题内容或保证D是实验文 |
| 研究只显示相关性，候选写因果 | 指出原文证据不能支持更强结论 | 迎合常识替文章补证明 |
| 七选五两项都含同一关键词 | 看空前、空后、指代及信息发展 | 只因词复现就选 |
| 完形只给空前半句 | 查完整语境或明确暂不能定 | 报唯一字母并捏造后文 |
| The city ___ I visited last year... | 根据从句缺宾语判断关系词 | 看city就填where |
| 作文缺题干 | 先改语言，暂缓内容与精确总分 | 认定跑题或漏要点 |
| Looking at the letter, tears... | 检查逻辑主语并给出语法成立的修改 | 只夸句式高级 |
| “I was very happy.” | 语法成立；按需讨论更具体的写法 | 标成语法错误 |
| “讲解2A”原稿可读 | 按原顺序展示整句再讲 | 自写同类场景替代原句 |
| “跑步不用ounce，换几种” | 给功能相近的不同表达及条件 | 罗列生僻同义词称随便替换 |
| “只要中文译文” | 中文译文，遵守本次范围 | 固定附完整英文讲解模板 |
| “已存入”操作失败 | 说清待入库，不编链接 | 只凭写入意图宣称成功 |
| “给真题动物描写”但无题源 | 核验或注明未核验；原创另标 | 自编句加浙江真题标签 |

人工评估五项：原文忠实、证据足够、题型方法正确、个人讲解风格、请求范围完成。结构校验不能证明英语答案或真实教学效果；独立样例通过也不能宣称全题型实测通过。

## 作文更新验收

- 应用文理由空泛：应给贴题的具体展开及主题表达，不能只换“有意义”的同义词。
- 续写情节断层：指出缺失节点并给合理安排，语言层落实为动作、反应与自然句群。
- 用户要求提高语言占比：语言应有实质篇幅，不能只有纠错或两个高级词；不为达到比例编造问题。
- 用户完成本次批改：结果不附批改后复核、再评分、改后自查、迁移练习等后续任务。
- 国内资料：说明作者／来源与实际读取范围，不能用旧划线关键词要求或国外量表当当前高考规定。
