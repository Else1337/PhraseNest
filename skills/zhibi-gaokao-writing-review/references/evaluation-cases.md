# 验收案例（行为测试；不是标注好的教师分数）

| 案例 | 预期行为 |
| --- | --- |
| A1 给完整应用文原题与作答，信息齐全但语言简单 | 先评交际完成，再评语言变化；简单不自动判错或封顶 |
| A2 应用文辞藻华丽但只有“活动很有意义” | 指出任务内容空洞，避免因为词汇复杂高估 |
| A3 应用文排序与示范排序不同，理由充分 | 不因选择不同而扣分；验证比较标准与说服力 |
| A4 只发作文不发题目 | 提供语言/结构有价值反馈；估分仅粗略、标缺题限制 |
| A5 学生英语正确但有更自然写法 | 使用U而非E，说明优化不是错误 |
| A6 学生要求只校对语法 | 不强制详述总分和创作改写 |
| C1 原文人物地位与学生续写人物关系相矛盾 | 精确引用原文事实，判为内容核心错 |
| C2 与示范不同但自洽的救援/比赛结果 | 不依赖唯一标准情节，不机械扣分 |
| C3 P1尾声未导向P2首句 | 指出具体断裂并给一条最小桥梁，不要求完全重写 |
| C4 华丽心理/风景描写却没有情节推进 | 指出内容质量问题而非只称语言优秀 |
| C5 非谓语逻辑主语错 | 原句+逻辑主语+最少修改+迁移句法规则 |
| C6 原文或首句缺失 | 不虚构任何伏笔，不给貌似权威的高置信分数 |
| X1 题目指定当次五档续写量规 | 用指定量规，不默认七档，不混淆数值边界 |
| X2 仅凭训练偏好应用文120词/续写200词 | 不将偏好设为该卷考试最低词数或扣分标准 |
| X3 手写图片模糊 | OCR歧义待核，不依推测判拼写错误或按字数扣分 |
| X4 用户说“直接讲完” | 完成解释与示范，不强制先问再答或二轮复核 |
| X5 用户只说“把这句存入Notion” | 查重、写入、回读（工具可用时）；不可用则明确未写入 |
| X6 重复出现一种语法错误 | 归类为一个可迁移知识点，显示必要位置，不刷屏式列十条 |
| X7 同学老师评分与模型估分差较大 | 保存双分与依据，分析冲突，不能假称二者完全一致 |
| X8 无新数据却试图承诺±1分 | 必须拒绝该准确性主张，给校准方案 |
