# 独立部署与迁移

用户已确认：独立部署、迁移数据、保留腾讯云版本、GitHub 新分支、完成后打包。

1. 当选择 standalone 模式时，程序只依赖自己的 PostgreSQL 与原件持久卷；cloudbase/postgres 旧分支行为不变。
2. 当导出源数据时，导出器不得写入源站；检测两次读取不一致时不得声称得到一致快照。
3. 当导入归档时，验证密码、版本、表清单、校验和和空目标库；失败不得留下可启动的半成品。
4. 当应用容器更新或重建时，账号、资料、对话、置顶、学习证据与原生记忆仍可读回。
5. GitHub 与公共构建产物不含真实数据、密钥、迁移归档或旧私有历史。
6. 无目标服务器时不切换网站；真实目标迁移与容器验收分别记录，不把准备完成写成已经迁移。
