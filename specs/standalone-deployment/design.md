# 技术设计

独立模式使用 PostgreSQL 的版本化业务表、CAS 文本存储与现有原生记忆格式。现有固定 RPC SQL 函数可在普通 PostgreSQL 运行，不需要 CloudBase HTTP 网关。学习库直接使用现有 PostgreSQL 适配。原件写入 Docker 命名卷，以业务键的 SHA-256 为文件名，数据库记录长度与校验和，不对公网暴露目录。

新增 standalone 开关，不改默认腾讯云入口。独立 Dockerfile、Compose、初始化/导入/导出命令与 worker 单独交付；初始化显式执行，不在每次应用启动时隐式建表或覆盖数据。

迁移归档带表级和原件级校验和，以 AES-256-GCM 加密；目标只接受空业务库。源站只读两轮校验，变化则中止并要求迁移窗口，避免声称这是数据库级事务快照。真实迁移资料仅放 D 盘私有目录，不进入 GitHub 或公开 Actions。

当前本机没有 Docker/WSL 发行版。优先静态/单元测试；公开分支 CI 使用演示数据执行 PostgreSQL、容器和重启验收。真实目标部署仍需服务器信息与迁移范围。
